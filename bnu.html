Building a Multilingual Web System for BNU

Creating a clearer, more responsive web experience across languages while strengthening brand expression.

Role: Product & Visual Design Intern
Timeline: May 2024 - Aug 2024
Company: BNU Corporation

View live website ↗

Background & Challenges

BNU is a women-focused skincare and hormonal health brand founded on the philosophy “Be Next to You, Be Nice to You.”

Website Challenges

Fragmented information architecture, poor mobile usability, and overcrowded multilingual navigation created friction across the website.

Design Challenge

Limited use of interaction and motion to communicate BNU's brand values within Squarespace's CMS constraints.

My Contributions

Working across UX, responsive design, localization, interaction, and visual design to improve the website within an existing CMS.

UX & Information Architecture

Restructured navigation and page layouts to create a clearer, more responsive web experience.

Localization

Developed a multilingual UX strategy within Squarespace constraints and redesigned the English and Chinese site experiences.

Interaction & Visual Design

Built custom hover interactions and landing-page motion graphics to strengthen BNU's digital brand expression.

Design Highlights

Selected work across responsive web design, localization, and brand-aligned visual design.

Responsive Web Design

Multilingual Experience

Brand Expression

Created landing-page animation to better communicate BNU's brand identity through the digital experience.

Key Takeaways

Designing Within Constraints

This first internship taught me how to design UX under real-world constraints, where CMS limitations, brand values, and user needs must be balanced through clear communication and iteration.

Collaborating with Stakeholders

I learned to communicate early, explore multiple design directions, and document iterations clearly so stakeholders could compare options and make decisions with greater confidence.
